# Operar Banco de Ads
## When to Use
Use para cadastrar, revisar ou pausar oportunidade local.
## Procedure
1. Declare origem FBR ou externa e URL
2. Valide type affiliate/product e dimensões permitidas
3. Registre status, validade, claims e disclosure
4. Deixe ativação e verba sob gate de Sergio
## Pitfalls
Banco local referencia FBR Ads; não duplica sua base central.
## Verification
Cada item tem origem, status, dimensões válidas e trilha de revisão.
